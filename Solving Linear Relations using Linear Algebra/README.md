# Solving Linear Relation using Linear Algebra

A paper (titled "How to Solve the Fibonacci Recursion using Linear Algebra") explaining, via the
companion matrix and its eigendecomposition, why the Fibonacci recursion
$R(n)=R(n-1)+R(n-2)$ has the closed-form (Binet) solution $R(n)=C_1\lambda_1^n+C_2\lambda_2^n$.
`code/validate.py` numerically checks the derived matrices against Wolfram Alpha's.
