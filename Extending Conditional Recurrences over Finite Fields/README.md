# Extending Condition Recurrences over Finite Fields (MATH6101 Project)

A paper (titled "Extending General Recurrences over Finite Fields" within the document) generalizing
conditional recurrence relations — recurrences whose $n^{th}$ term depends on the residue of $n$ modulo
some $r$ — from conditioning on residues mod an integer $r$ to conditioning on residues over a finite
field. Includes a Java program (`code/src/Recursion.java`) used to compute terms of these recurrences.
